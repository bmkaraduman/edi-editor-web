What is worth writing about?

  • My file does not display correctly. The most valuable kind of feedback. Telling me the message type and what looks wrong is enough — please do not send the file itself, it contains commercial data. If I need more, I will ask for a few anonymised lines.
  • A missing segment or code. Let me know if you cannot find a segment in the reference, or if a qualifier has no description.
  • A translation error. Descriptions exist in seven languages; if something reads wrong, tell me which language and which page.
  • A feature request. Knowing which message type you need a PDF for helps me decide what to build next.

Privacy

Form submissions are delivered through a third-party service called FormSubmit, which forwards your message to me by email. The name, email address and message you provide are used only to reply to you; they are not used for marketing and are not shared with third parties. See the Privacy Policy for details.

EDI files you open in the application are entirely separate from this form and are never sent to a server. The form transmits only the text you type into it.

Response time

ediviewer is a one-person project. I usually reply within a few days, though it can take longer during busy periods. Bug reports get priority.
