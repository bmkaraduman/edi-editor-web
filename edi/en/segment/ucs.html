UCS — Faulty Segment Information

EDIFACT segment
📘

Identifies the segment in which the error was found. The value is the segment position counted from the start of the message, so you can go straight to that line in the file you sent.

Example

UCS+12'

Data Elements

Pos.Description
01Segment Position
02Segment Tag

Watch out

The count starts at the UNH segment and belongs to the message, not to the whole file. In an interchange carrying several messages, confusing this position with a line number in the file sends you to the wrong place.
