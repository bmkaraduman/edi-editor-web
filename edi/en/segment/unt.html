UNT — Message Trailer

EDIFACT segment
📘

Closes the message, repeating the number of segments it contains (including UNH and UNT) and the reference number from UNH.

Example

UNT+35+ME000001'

Data Elements

Pos.Description
01Number of Segments in Message
02Message Reference Number

Watch out

If the segment count does not match, the receiving system usually rejects the message; the count acts as a checksum against truncation.
