UNS — Section Control

EDIFACT segment
📘

Section separator. Marks the end of the detail section and the start of the summary section.

Example

UNS+S'

Data Elements

Pos.Description
01Section Separator

Code List

CodeMeaning
DHeader/Detail Separation
SDetail/Summary Separation

Watch out

The value S stands for summary. MOA segments after this point are message-level totals, not line amounts.
