GIN — GOODS IDENTITY (Label/Pallet No)

EDIFACT segment
📘

Carries an identity number. The BJ qualifier denotes an SSCC, the serial shipping container code of a pallet or carton.

Example

GIN+BJ+340123456789012345'

Data Elements

Pos.Description
01Identity Number Type
02Identity Number

Code List

CodeMeaning
AWItem Barcode (UPC/EAN)
BJSSCC (Container Code)
BNSerial Number
BXBatch / Lot Number
GBBuyer Stock Number
SNSeal Number
VVVehicle Identification No (VIN)

Watch out

The SSCC must match the barcode physically scanned at goods-in; if it does not, receiving automation stops.
