FTX — Free Text / Description

EDIFACT segment
📘

Carries a free-text note: a delivery instruction, a payment condition or a general remark.

Example

FTX+AAI+++TESLIMAT 08.00-16.00 SAATLERI ARASINDA YAPILACAKTIR'

Data Elements

Pos.Description
01Text Subject
04Text Content

Watch out

Free text is not machine-interpretable, so putting critical information only in an FTX breaks automation. A colon inside the text must be escaped with the release character (?).
