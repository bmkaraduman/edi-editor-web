UCM — Message Response

EDIFACT segment
📘

Reports the outcome for a single message inside the interchange. Because one transmission can carry several messages, UCI assesses the interchange as a whole while UCM assesses each message separately.

Example

UCM+1+ORDERS:D:96A:UN+7'

Data Elements

Pos.Description
01Message Reference No
02Message Identifier

Code List

CodeMeaning
4Rejected
7Accepted
8Found Faulty

Watch out

An interchange can be accepted while a message inside it is rejected. Looking only at the UCI code is therefore misleading; the per-message result has to be read from the UCM lines.
