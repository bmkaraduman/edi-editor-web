INV — Inventory Management Info

EDIFACT segment
📘

States the type of an inventory movement. In an inventory report it determines what a quantity means: stock on hand, sold, returned or damaged.

Example

INV+1+1'

Data Elements

No element descriptions are defined for this segment.

Code List

CodeMeaning
1Stock Movement (Transfer)
2Stock Difference / Correction
3Stock Status Change

Watch out

The quantity itself is carried by QTY; INV only says what kind of quantity it is. Processing an inventory report without reading the two together leads to errors such as adding returns to stock on hand.
