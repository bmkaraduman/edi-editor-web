UCD — Error Detail / Code

EDIFACT segment
📘

States the reason for the error and exactly which data element caused it. UCS says which segment; UCD says which element within that segment was not accepted, and why.

Example

UCD+13+QTY+2'

Data Elements

Pos.Description
01Error Code

Code List

CodeMeaning
12Invalid Value
13Missing Mandatory Field
14Unsupported Value
15Unsupported Segment

Watch out

The error code tells you the kind of problem, not the fix. 13 means a mandatory field is missing, 12 an invalid value, 14 an unsupported value and 15 an unsupported segment. Which field is mandatory is defined by your trading partner’s specification.
