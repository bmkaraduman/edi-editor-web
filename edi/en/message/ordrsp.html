ORDRSP — ORDER RESPONSE (ORDRSP)

EDIFACT Message Type
📄

Confirms that an order is accepted, partially accepted or rejected. The response can differ line by line.

Who sends it

Sent by the supplier in response to an order.

The value of ORDRSP lies in its per-line answers: the action code on the LIN segment is 5 for accepted, 7 for rejected and 3 for a proposed change. A supplier can therefore say "I can ship three items, the fourth is out of stock".

Reasons for a rejection or a change are normally carried in an FTX. The buyer's system processes the response automatically and updates the order.

Typical Segment Flow

UNB → UNH → BGM → DTM → RFF → NAD → LIN → QTY → PRI → UNT → UNZ
